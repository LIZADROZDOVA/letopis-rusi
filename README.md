# ЛЕТОПИСЬ РУСИ — финальная версия

Интерактивное учебное веб-приложение по истории Руси и Восточной Европы.

## Возможности
- 10 последовательных эпох/уроков
- подробные учебные карточки
- поиск по курсу
- большая хронология
- учебная карта Днепра и ключевых центров
- персоналии
- интерактивный тест
- XP и прогресс
- сохранение прогресса в localStorage
- адаптивный дизайн для телефона и компьютера
- чистый HTML/CSS/JS без зависимостей

## Запуск в VS Code
1. Распакуйте ZIP.
2. Откройте папку `istoriya-rusi-final` в VS Code.
3. Откройте `index.html`.
4. Для удобной разработки установите расширение Live Server и нажмите `Go Live`.

## Важная историческая методика
Приложение намеренно не сводит историю к формуле «Рюрик → Русь → Россия».
Для раннего периода нужно различать:
- археологические культуры;
- этнонимы в письменных источниках;
- политические образования;
- языковые общности;
- современные национальные идентичности.

Следующий этап развития проекта: полноценная база источников, интерактивная карта по векам, изображения археологических находок, первичные тексты (с переводами), аудиоуроки и расширенный банк вопросов.
